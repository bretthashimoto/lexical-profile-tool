Step-by-step guide

Quick start

See how it works: profile seven of Aesop's Fables against the COCA word list, before building your own reference or uploading your own texts.

  1. Build a reference (step 1, on the "Profile a text" page). Pick one:
    • Built-in word list — profile against a published list (AVL, NGSL, NAWL, or COCA) with no file to find or format.
    • Corpus of texts — upload your own .txt/.docx/.pdf files (or pick a whole folder) and the reference builds automatically from their word frequencies.
    • Word list / saved reference — upload your own plain-text or word,frequency list (.txt), or reload a reference you exported earlier (.json).
    While you're at it, set the band size, language, and whether to lemmatize — these affect how words are grouped and matched, so set them before building rather than after.

    Ignore (optional), at the bottom of the same page: proper nouns and digits are excluded by default — uncheck either box to profile it like any other word instead. Upload or paste specific words (names, made-up words, etc.) you don't want counted as off-list.
  2. Profile target text(s) (step 2, further down the same page). Upload files or paste text directly -- profiling starts automatically once a reference exists.
  3. Read the results (step 3, appended below once profiling finishes):
    • The summary table and metrics show tokens, types, and off-list % (plus ignored/proper noun/digit %, if applicable) per text.
    • The band coverage chart shows what % of tokens fall in each band, plus cumulative coverage against the 95%/98% thresholds.
    • Highlighted text color-codes every word by band (or off-list/ignored/proper noun/digit), so you can see at a glance which words are driving the score.
    • Export lets you download the band coverage, full report, and off-list/ignored/proper-noun/digit word lists as CSV/JSON.

Not sure what any of this means? See the About lexical frequency profiling page for background on bands, coverage thresholds, and how lemmas/POS matching work.
